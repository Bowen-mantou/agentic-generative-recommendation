## 1. 结论摘要

1. **Q1-B（外部权重）不成立**：截至 2026-11-24 未发现任何 TIGER 端到端预训练权重，
   也没有覆盖 Amazon Reviews 2023 `All_Beauty` 的权重；只存在其他数据集的 RQ-VAE
   tokenizer 权重，且 decoder/T5 权重不存在。
2. **Q1-B 只能兑现为“外部代码复用”**：存在许可证可用的社区实现（Cornac、RQ-VAE-Recommender、
   TIGER 复现、torch-rechub 等），但仍需在本项目 112,590 个商品上重新训练 RQ-VAE 与生成器。
3. **数据规模很小**：694,252 条事件分布在 **631,986 个用户**上；可用于 next-item 训练的用户
   序列为 ≥3 事件 **8,201 条**、≥5 事件 **1,477 条**、≥10 事件 **324 条**。
4. **Semantic ID 冲突率高**：用 E5 向量 + 3 级 k-means（每级 256）代理量化，
   3 个 token 只有 **79,207 个唯一 ID**（112,590 商品中 **44.3% 与他人冲突**，单 ID 最多 93 个商品）；
   4 级 × 1024 也只有 **102,735 个唯一 ID（14.3% 冲突）**。
5. 按 Q1 规则，上述事实应提交负责人确认后再决定是否进入自建（A）；**本文件不自行启动训练**。

### 2.3 Semantic ID 冲突（零训练代理实验）

方法：对已建 E5 向量（112,590 × 768，L2 归一化）做 3/4 级 k-means（每级 k=256/1024，
kmeans niter=20, seed=42, faiss CPU），逐级取残差后统计前缀唯一 ID 数与冲突率。
这是 **量化代理**，不是训练好的 RQ-VAE，仅用于判断码本容量是否足够。

| 配置 | 唯一 ID 数 | 冲突商品占比 | 单 ID 最大商品数 | 每级训练耗时 |
|---|---|---|---|---|
| 3 级 × 256 | 79,207 | **44.3%** | 93 | 2.7 s / 级 |
| 4 级 × 1024 | 102,735 | **14.3%** | 28 | 6.1-6.5 s / 级 |

含义：Semantic ID → `product_id` 解码必然是“一对多”，需要在解码后做商品级排序/约束过滤；
4 级 × 1024 可显著降低冲突但计算与词表更大。

## 3. 资源估算（CPU 基线，Q11；均为估算，未经训练验证）

| 环节 | 估算 | 依据/风险 |
|---|---|---|
| RQ-VAE 训练（112,590×768） | 30–90 分钟 CPU（20 epochs） | 代理 k-means 每级约 3–7 s；真实 RQ-VAE 含 encoder/decoder 与码本更新，按 10–30× 代理计算量估 |
| 生成器训练（T5-small 60M，8,201 条 ≥3 序列） | 1–2 小时 CPU / 20 epochs（batch 64，约 128 步/epoch） | 数据太少，loss 可下降但泛化不可信；无 GPU（Q11） |
| 训练数据规模 | 8,201 条（≥3）；43,044 条（≥2，但每条只有 1 个 next-item 目标） | 见 §2.2 |
| 人时 | **20–30 人时**（B 阶段：数据/训练/解码/集成/评测） | 不含阶段 A 调优；4 级×1024 与 beam search 调参另计 10–15 人时 |
| 存储 | 检查点 0.5–1 GB + ID 映射表（< 100 MB），放 NFS | Q10 |
| 预期收益 | 未知；在 8,201 条序列上训练的小模型很可能不优于 E5 语义召回 | 需要在 Phase 7 用 Recall/NDCG 对照验证，不能先验宣称收益 |

## 4. 可选路径（互斥，等待确认）

| 选项 | 内容 | 关键影响 |
|---|---|---|
| A1 | 自建 3 级 × 256 RQ-VAE + 小型生成器，使用 ≥3 序列（8,201） | 冲突率 44.3%，解码必须一对多；训练量最小；质量风险最高 |
| A2 | 自建 4 级 × 1024 RQ-VAE + 生成器，使用 ≥2 或 ≥3 序列 | 冲突率 14.3%，词表/计算更大；≥2 序列仅 1 个监督目标 |
| A3 | 先做 1–2 天 pilot（仅 RQ-VAE + 少量序列过拟合检查），再决定是否全量 | 增加 2–3 人时；降低“训练完才发现不可用”的风险 |
| A4 | 暂缓 TIGER，用 E5 单路完成 Phase 2/3/5/6，按 Q12 提交偏差说明 | 无法宣称完成“TIGER + E5 双路”验收；Phase 7 实验 E2/E3 需改期 |
| A5 | 扩展品类或外部数据以增加序列 | 与 Q5（第一阶段仅 All_Beauty）冲突，需先改 Q5 |
